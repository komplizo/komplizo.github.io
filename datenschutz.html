DATENSCHUTZ

Stand: 17.11.2026

Worum geht es?

Diese Datenschutzerklärung gilt für die Anwendung „Komplizo Upload“. Die Anwendung wird ausschließlich vom Betreiber des YouTube-Kanals Komplizo genutzt, um eigene Videos auf den eigenen Kanal hochzuladen.

Welche Daten werden genutzt?

Die Anwendung nutzt über die YouTube Data API (Google OAuth) nur die Berechtigung, Videos, Titel, Beschreibungen, Thumbnails und Playlists auf dem eigenen Kanal zu verwalten. Es werden keine Daten anderer Personen abgerufen, gespeichert oder weitergegeben.

Speicherung

Das Zugangs-Token wird ausschließlich lokal auf dem Rechner des Kanalbetreibers gespeichert. Es gibt keine Server, keine Datenbank, kein Tracking, keine Cookies und keine Werbung auf dieser Seite.

Weitergabe

Daten werden nicht verkauft und nicht an Dritte weitergegeben. Die Nutzung von Google-Diensten unterliegt der Datenschutzerklärung von Google. Die Anwendung hält sich an die Google API Services User Data Policy.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
